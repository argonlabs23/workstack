# ASD-STE100 Controlled Vocabulary & Dictionary Reference

This dictionary provides approved ASD-STE100 replacements for non-approved, verbose, ambiguous, or complex English words and phrases.

---

## 1. Verbs (Action Words)

| Non-Approved Verb | Approved STE Replacement | Example / Context |
| :--- | :--- | :--- |
| **utilize** / **employ** | `use` | Use the tool (not: Utilize the tool). |
| **commence** / **initiate** / **begin** | `start` | Start the pump (not: Initiate the pump). |
| **terminate** / **discontinue** / **abort** | `stop` | Stop the process (not: Terminate the process). |
| **perform** / **execute** | `do` / *(specific verb)* | Do the check / Test the system. |
| **obtain** / **acquire** / **procure** | `get` | Get the replacement part. |
| **demonstrate** / **indicate** / **exhibit** | `show` | The display shows the temperature. |
| **ascertain** / **determine** | `find` / `check` | Check the voltage level. |
| **facilitate** | `help` / `make easy` | This bracket helps installation. |
| **implement** | `do` / `put in place` | Do the procedure. |
| **illuminate** | `turn on` / `come on` | The red light comes on. |
| **depress** | `push` | Push the button (not: Depress the button). |
| **inspect** / **examine** | `check` | Check the cable for damage. |
| **verify** / **validate** | `make sure` / `check` | Make sure that the valve is closed. |
| **modify** / **alter** | `change` | Change the parameter setting. |
| **fabricate** / **construct** | `make` / `build` | Make a new connector cable. |
| **attempt** | `try` | Try to restart the unit. |
| **succeeding** | `following` | Do the following steps. |

## 2. Nouns & Abstract Jargon

| Non-Approved / Verbose Noun | Approved STE Replacement | Example / Context |
| :--- | :--- | :--- |
| **utilization** / **usage** | `use` | The use of this tool... |
| **requirement** | `need` / *(rephrase with `must`)* | You must wear goggles (not: Goggles are a requirement). |
| **facility** | `building` / `shop` / `room` | Specific name of place. |
| **apparatus** / **device** | `unit` / `tool` / *(specific name)* | Use the test unit. |
| **methodology** | `method` | Follow this method. |
| **componentry** | `components` / `parts` | Replace defective parts. |
| **indication** | `signal` / `reading` | Record the reading on the display. |
| **discrepancy** | `difference` / `fault` | Report any difference in dimensions. |

## 3. Prepositions & Transition Phrases

| Non-Approved / Verbose Phrase | Approved STE Replacement | Example / Context |
| :--- | :--- | :--- |
| **in order to** | `to` | Push the button to start the motor. |
| **prior to** | `before` | Disconnect power before maintenance. |
| **subsequent to** / **following upon** | `after` | Inspect the unit after testing. |
| **due to the fact that** / **in view of** | `because` | The engine stopped because fuel was low. |
| **at this point in time** / **currently** | `now` | Power down the system now. |
| **in the event that** / **should there be** | `if` | If pressure drops, open the valve. |
| **with regard to** / **in reference to** | `about` | Contact support for details about safety. |
| **for the purpose of** | `for` / `to` | Designed to prevent leaks. |
| **in close proximity to** | `near` | Do not place fluids near the console. |
| **in accordance with** | `following` / `per` | Follow procedure A. |

## 4. Adjectives & Adverbs

| Non-Approved Word | Approved STE Replacement | Example / Context |
| :--- | :--- | :--- |
| **approximately** | `about` | Wait for about 5 minutes. |
| **sufficient** | `enough` | Make sure there is enough oil. |
| **additional** | `more` / `extra` | Add more coolant. |
| **subsequent** | `next` / `later` | See the next section. |
| **prior** | `earlier` / `previous` | Refer to the previous step. |
| **essential** / **vital** / **imperative** | `necessary` / `important` | It is necessary to ground the wire. |
| **instantaneously** / **immediately** | `at once` / `immediately` | Stop the motor at once. |
| **substantially** | `much` / `significantly` | The reading changed significantly. |
| **optimum** / **optimal** | `best` | Select the best setting. |

## 5. Unapproved Synonyms to Avoid

| Avoid | Use Instead |
| :--- | :--- |
| **allow**, **permit**, **enable** | `let` / `allow` |
| **select**, **pick**, **choose** | `select` |
| **observe**, **monitor**, **watch** | `check` / `watch` |
| **inform**, **notify**, **advise** | `tell` |
| **ensure**, **insure**, **assure** | `make sure` |
| **location**, **position**, **place** | `position` / `place` |
